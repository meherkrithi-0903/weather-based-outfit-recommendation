# MyOutfit
A Streamlit web application that recommends outfits based on real-time weather conditions.

# Features
- Takes live weather data using OpenWeatherMap API
- Considers temperature, humidity, and rain
- Region-aware recommendations (Indian vs Global)
- Clean, interactive UI built with Streamlit
- Graceful error handling and input validation

# Tech Stack
- Python
- Streamlit
- OpenWeatherMap API

# How to Run Locally
```bash
pip install -r requirements.txt
python3 -m streamlit run app.py
